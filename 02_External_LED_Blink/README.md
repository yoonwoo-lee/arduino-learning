# External LED Blink

## Purpose

After successfully blinking the built-in LED, I wanted to learn how to control an external component using a breadboard. This project helped me understand how to build my first simple circuit outside of the Arduino board itself.

## What I Learned

Although still a simple project, it introduced me to several important electronics concepts:

* How to wire an LED on a breadboard.
* Why LEDs require a current-limiting resistor.
* How breadboard rows and columns are connected.
* The importance of LED polarity (anode and cathode).
* How `pinMode()`, `digitalWrite()`, and `delay()` can be used to control external components.
