# Arduino Push Button

## Purpose
Learn how push buttons work as digital inputs and how to detect button presses using an Arduino.

## What I Learned
- How a push button sends HIGH and LOW signals.
- The difference between INPUT and INPUT_PULLUP modes.
- Why pull-up and pull-down resistors are needed.
- How to read button states using `digitalRead()`.
- How to use button input to control an LED.
