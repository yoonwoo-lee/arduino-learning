# Active Buzzer

## Purpose

Learn how to control an active buzzer with Arduino by turning it on and off to produce simple sound alerts.

## What I Learned

* How an active buzzer differs from a passive buzzer.
* How to use `digitalWrite()` to control the buzzer.
* How `HIGH` and `LOW` turn the buzzer on and off.
* How `delay()` controls the length and timing of the sound.
