# Passive Buzzer

## Purpose
Learn how to control a passive buzzer with Arduino by driving it at different frequencies to produce actual musical notes, instead of just one fixed tone.

## What I Learned
- How a passive buzzer differs from an active buzzer (no built-in oscillator, so it needs Arduino to generate the actual frequency).
- How to use `tone()` to play specific pitches.
- How frequency directly maps to musical notes (e.g., higher frequency = higher pitch).
- How to play a simple ascending scale by stepping through increasing frequencies.
