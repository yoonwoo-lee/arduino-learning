# Tilt Ball Switch

## Purpose
Learn how a tilt ball switch detects changes in orientation and how it can be used as a simple motion sensor.

## What I Learned
- How a tilt ball switch works internally.
- How to read digital input from a sensor.
- How the switch changes between HIGH and LOW depending on its orientation.
- How to use an `if` statement to respond to sensor input.

## Notes
It's surprisingly satisfying to hear the tiny metal ball rolling around inside the switch. Such a simple component, but it opens the door to projects like tilt alarms, orientation detectors, and motion-activated devices.
