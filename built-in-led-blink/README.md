# Built-in LED Blink

## Purpose

I wanted to test out my first-ever Arduino board, ensuring that the connection to my computer was established and that all required software was installed and functioning properly. 

## What I learned

Although a simple project, blinking my built-in LED has taught me many important functionalities of the Arduino kit:

- How to upload code to an arduino board
- The purpose of many of the components located on the Arduino itself
- How core software functions work, including digitalWrite(), pinMode(), setup(), loop(), and delay()

## Result

Successfully blinked the built-in LED and verified that my Arduino environment was set up correctly.
